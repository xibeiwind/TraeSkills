# Daily Priority Focus

这是一个智能的每日工作优先级聚焦技能，帮助用户高效管理任务、确定优先级并保持专注。

## 功能特性

### 核心功能
- **智能任务排序**：基于综合评分算法（重要性、紧急性、难度、时间）自动排序任务
- **提醒功能**：在任务截止前或特定时间提醒用户
- **专注模式**：提供专注模式，屏蔽干扰，专注于当前任务
- **进度跟踪**：跟踪任务完成进度和效率统计

### 交互方式
- **命令行界面**：快速操作和自动化
- **图形界面**：可视化的任务管理和优先级展示
- **语音交互**：通过语音命令与技能交互

### 任务收集方式
- **手动输入**：用户手动输入任务信息
- **语音录入**：通过语音录入任务信息
- **从其他应用同步**：从待办事项应用（如Todoist、Microsoft To Do等）同步任务

### 展示方式
- **列表形式**：以列表形式展示任务，清晰易读
- **时间轴**：以时间轴形式展示任务，直观显示时间安排
- **可视化图表**：使用图表（饼图、柱状图等）可视化展示任务分布

### 集成功能
- **日历应用集成**：与日历应用集成，同步日程安排
- **待办事项软件集成**：与待办事项软件（如Todoist、Microsoft To Do等）集成

## 使用场景

当用户遇到以下情况时，应该调用此技能：

1. 需要管理每日工作任务时
2. 需要确定任务优先级时
3. 需要进入专注模式工作时
4. 需要跟踪任务进度时
5. 需要查看任务统计和分析时
6. 需要设置任务提醒时
7. 需要从其他应用同步任务时

## 优先级算法

技能使用综合评分算法来确定任务优先级，考虑以下因素：

1. **重要性**（权重：30%）：任务的重要程度
2. **紧急性**（权重：25%）：任务的紧急程度和截止日期
3. **难度**（权重：20%）：任务的难度和复杂度
4. **时间**（权重：15%）：任务预计完成时间
5. **依赖关系**（权重：10%）：任务之间的依赖关系

## 使用示例

### 命令行界面使用

```bash
# 添加任务
daily-priority add "完成项目报告" --importance high --urgency medium --difficulty medium

# 查看任务列表
daily-priority list --view timeline

# 进入专注模式
daily-priority focus --task-id 1 --duration 60

# 查看进度统计
daily-priority stats --period week
```

### 语音交互使用

```
用户："添加一个任务，完成项目报告，重要性高，紧急性中等"
技能："已添加任务：完成项目报告，优先级评分：85"

用户："进入专注模式，专注第一个任务"
技能："已进入专注模式，专注任务：完成项目报告，预计时间：60分钟"
```
