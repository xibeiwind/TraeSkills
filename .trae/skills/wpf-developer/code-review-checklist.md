## 概述

本清单用于 WPF 项目的代码审查，帮助团队确保代码符合最佳实践，提高代码质量和可维护性。

## MVVM 模式检查

### View 层

| 检查项 | 描述 | 状态 |
|--------|------|------|
| 无业务逻辑 | View 不应包含业务逻辑，所有逻辑应在 ViewModel 中 | [ ] |
| Code-behind 简洁 | Code-behind 仅包含 UI 初始化代码 | [ ] |
| DataContext 设置正确 | 通过 XAML 声明方式设置 DataContext | [ ] |
| 无控件直接引用 | ViewModel 不应直接引用 UI 控件 | [ ] |
| 使用数据模板 | 使用 DataTemplate 定义数据展示 | [ ] |

### ViewModel 层

| 检查项 | 描述 | 状态 |
|--------|------|------|
| INotifyPropertyChanged | 所有绑定属性实现 PropertyChanged 通知 | [ ] |
| 无 View 引用 | ViewModel 不应引用 View 类型 | [ ] |
| 命令实现正确 | 使用 ICommand 接口，CanExecute 逻辑完整 | [ ] |
| 属性命名规范 | 使用 PascalCase 命名 | [ ] |
| 无 UI 线程阻塞 | 耗时操作在后台线程执行 | [ ] |

### Model 层

| 检查项 | 描述 | 状态 |
|--------|------|------|
| 业务逻辑封装 | Model 包含核心业务逻辑 | [ ] |
| 无 UI 依赖 | Model 不应引用任何 UI 类型 | [ ] |
| 数据验证 | 实现 IDataErrorInfo 或 INotifyDataErrorInfo | [ ] |
| 实体设计合理 | 属性简洁，无冗余字段 | [ ] |
